# Skill Generator Pro - AI Skill创建助手

## 🎯 概述

一个智能的AI skill生成器，能够分析用户需求，识别模糊或不完整的信息，提供优化建议，并生成适用于Claude、GPT、DeepSeek等多个平台的通用skill文件。该skill通过系统化的需求分析、智能提问和结构优化，确保生成的skill文件完整、清晰且易于维护。

## 🔧 核心能力

1. **[需求分析引擎]**：[解析用户初始需求，识别关键功能点，评估需求完整性和清晰度，识别潜在的设计冲突和逻辑问题，分析跨平台兼容性需求]

2. **[智能提问系统]**：[自动识别模糊不清的需求部分，生成优先级分类的问题清单，提供具体的选项和建议，引导用户完善需求细节]

3. **[结构优化器]**：[建议最优的skill结构设计，优化命名规范和分类体系，确保跨平台兼容性，提供最佳实践建议]

4. **[文件生成器]**：[生成标准化的skill文件，包含完整的元数据和文档，适配多平台格式要求，提供版本管理和更新建议]

## 📖 使用指南

### 基本用法
[用户只需描述想要创建的skill功能，系统会自动分析需求并提出澄清问题。用户回答这些问题后，系统会生成完整的skill文件。例如：用户说"我想要一个管理待办事项的skill"，系统会调用 skill-generator-pro 询问待办事项的属性、是否需要提醒、数据存储方式等问题，然后生成完整的skill文件]

### 高级功能
[支持批量生成多个skill文件，支持自定义模板，支持从现有skill中学习模式，支持导出为不同平台的特定格式，支持版本对比和回滚功能]

### 配置选项
[可配置生成的skill文件格式（Markdown/YAML/JSON），可配置提问的详细程度（简单/标准/详细），可配置是否自动添加示例，可配置目标平台列表，可配置输出语言]

## 📥 输入输出规范

### 输入
- **类型**：[文本描述，可包含功能需求、使用场景、特殊要求]
- **格式**：[自然语言文本，支持中英文，可包含列表和要点]
- **限制**：[单次输入建议不超过2000字，如需更复杂需求建议分多次输入]
- **示例**：[用户输入："创建一个能分析文本情感并给出评分和建议的skill"]

### 输出
- **类型**：[完整的skill文件内容，包含元数据、功能描述、使用指南、示例等]
- **格式**：[Markdown格式，包含YAML front matter，兼容主流AI平台]
- **结构**：[包含description、platforms、capabilities、workflows、examples、error_handling、limitations等完整结构]

## ⚠️ 错误处理
| 错误类型 | 处理方式 | 示例 |
|---------|---------|------|
| [需求过于模糊] | [提出具体的澄清问题，引导用户提供更多细节] | [用户说"做个有用的工具"，系统询问具体功能和使用场景] |
| [需求包含矛盾] | [指出矛盾之处，提供修改建议] | [用户要求"快速处理大量数据"同时要求"使用最少资源"] |
| [超出平台能力] | [说明限制，提供替代方案] | [用户要求访问本地文件系统，建议使用API或云存储] |
| [信息不完整] | [列出缺失的关键信息，提供默认选项] | [缺少错误处理策略，提供标准错误处理模板] |

## 🔒 限制说明
- [生成的skill文件质量取决于用户提供的信息详细程度，信息越详细生成的skill越完善]
- [不支持生成需要特殊权限或访问底层系统资源的skill]
- [生成的skill需要用户在目标平台上手动测试和调整]
- [对于高度专业化的领域，可能需要领域专家的额外输入]
