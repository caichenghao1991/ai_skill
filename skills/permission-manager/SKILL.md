# Permission Manager — AI 操作权限管理 Skill

## 🎯 概述

本 Skill 允许用户动态管理当前 AI 会话中的操作权限，通过“权限组合（Permission Profile）”的方式批量授予或拒绝特定类型的操作（如数据库访问、Kubernetes 操作、文件读写、API 调用等）。权限组合可保存为文件并上传至 GitHub，便于跨会话复用和共享。同时，权限会在次日自动重置为默认安全状态，或由用户手动撤销。

---

## 🔧 核心能力

- **权限组合管理**：支持创建、查看、修改、删除权限组合（Profile）。
- **权限切换**：用户可切换到指定权限组合，立即生效，覆盖当前所有权限。
- **精细权限控制**：每个权限项可设置为“授予（allow）”或“拒绝（deny）”，未明确声明的权限默认为空（即不授予）。
- **持久化存储**：权限组合文件可上传至 GitHub 仓库（用户需提前配置仓库地址和 token）。
- **自动失效**：权限组合默认仅在当天有效，次日自动恢复为默认（无特殊权限）状态；用户也可主动关闭。
- **无需手动确认**：权限变更后，后续操作自动按新权限执行，不再弹窗确认（在权限范围内）。

## 📖 使用指南

### 触发条件

当用户说出以下意图时，自动触发本 Skill：
- “我想修改当前权限”、“切换权限”、“启用权限组合”
- “查看权限”、“显示权限文件”
- “修改 [组合名] 权限”、“编辑 [组合名]”
- “删除 [组合名] 权限”
- “新建权限组合”、“创建权限组合”
- “关闭权限”、“移除权限组合”、“恢复默认权限”

### 基本操作流程

#### 1. 查看当前权限或所有组合
- **用户**：`“查看权限”` 或 `“显示所有权限组合”`
- **系统**：返回当前生效的权限组合名及详细权限列表，或列出所有已保存的组合文件（从 GitHub 拉取列表）。

#### 2. 切换权限组合
- **用户**：`“切换到 [组合名]”` 或 `“启用 [组合名]”`
- **系统**：
  1. 从存储（本地或 GitHub）加载指定组合的权限定义。
  2. 应用该组合，覆盖当前所有权限。
  3. 回复确认信息，并列出新启用的权限。
  4. 记录启用时间，设定次日自动失效。

#### 3. 新建权限组合
- **用户**：`“新建权限组合，名称叫 devops”` 或 `“创建权限组合 prod，允许数据库和 K8s，拒绝文件写入”`
- **系统**：
  1. 解析用户描述，提取组合名、允许列表、拒绝列表（未提及的权限项默认为空）。
  2. 生成权限组合文件（格式见下文）。
  3. 询问用户是否上传至 GitHub（若已配置）。
  4. 可选择立即启用该组合。

#### 4. 修改已有权限组合
- **用户**：`“修改 devops 组合，增加 API 调用权限”`
- **系统**：
  1. 询问用户希望以何种方式修改：**直接语言描述**（如“增加...删除...”）还是**提供新文件**。
  2. 若选择语言描述，解析变更指令并更新组合定义。
  3. 若选择提供新文件，用户需上传文件内容（或粘贴），系统替换原有组合。
  4. 更新存储（本地/GitHub）并反馈结果。

#### 5. 删除权限组合
- **用户**：`“删除 devops 组合”`
- **系统**：
  1. 确认删除操作（防止误删）。
  2. 若当前正在使用该组合，则自动切回默认（无权限）并提示。
  3. 从存储中移除该组合文件。

#### 6. 关闭/移除权限组合
- **用户**：`“关闭权限”`、`“移除 devops 组合”` 或 `“恢复默认权限”`
- **系统**：
  1. 立即清空所有特殊权限，恢复为默认（无任何授予的权限）。
  2. 若指定组合名，则仅停用该组合，但保留文件，如需彻底删除需使用删除操作。

## 📥 权限组合文件格式

每个权限组合存储为 JSON 或 YAML 文件（推荐 YAML），结构如下：

```yaml
name: devops
description: 开发和运维常用权限
created: 2026-08-18
allowed:
  - database:read
  - database:write
  - kubernetes:list
  - kubernetes:apply
  - file:read
  - api:call
denied:
  - file:write
  - kubernetes:delete
